Place your homepage banner images here (.jpg, .jpeg, .png or .webp).

If you (or Claude) regenerate the site by running "node build.js" or by
using Admin Studio's "Generate Website" button, this folder is scanned
automatically — whatever images are here become the banner slider, in
alphabetical order. New images default to linking to all-services.html;
you can change a banner's link afterwards in Admin Studio > Home Banners.
