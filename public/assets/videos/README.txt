Place your welcome video(s) here (.mp4 or .webm).

If you (or Claude) regenerate the site by running "node build.js" or by
using Admin Studio's "Generate Website" button, this folder is scanned
automatically — whatever video files are here become the playlist, in
alphabetical order. You no longer need to type filenames into
site-data.json by hand.

The player autoplays muted, shows normal browser video controls, and
moves to the next file when one ends; after the last file it loops back
to the first one.
